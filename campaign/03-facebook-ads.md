# Facebook & Instagram Ad Copy — All 4 Segments

Format: Meta single-image/video ads. Recommended lengths: Primary text
~125 characters before truncation (up to 2200 allowed, keep the hook in
the first sentence), Headline ~40 characters, Description ~30 characters
(shown in some placements only). Two variants per segment (`a1`/`a2`).
Swap in `utm_content=fb_{variant}` on each link per the convention in
`00-foundations.md`.

**Reminder:** every ad set built from this copy runs under Meta's Special
Ad Category for Credit — no age or gender targeting on any of these (see
`00-foundations.md`). This applies at ad-set setup, not to the copy itself,
but don't build an ad set around this copy that tries to add age/gender
targeting; it will be rejected or auto-corrected.

Priority order matches platform fit from `01-audience-targeting.md`:
Divorce and Inheritance are the primary Facebook segments; Job Loss and
Early Retirement run here too but split budget with LinkedIn, which is
the stronger platform for those two.

**All copy below is a draft pending compliance approval — do not launch
before sign-off (see `00-foundations.md`).**
