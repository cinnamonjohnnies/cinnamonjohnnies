# Content Style Rules

Standing rules for anything written in this repo, website copy, lead
magnets, emails, campaign material, and docs alike. Apply these before
publishing or submitting anything for compliance review.

## No em dashes, anywhere

Never use an em dash (—) or the `&mdash;` HTML entity in any content.
Use a comma, colon, semicolon, period, or parentheses instead, whichever
reads most naturally for that sentence. When restructuring a sentence to
remove a dash, prefer breaking it into two shorter sentences over forcing
a comma splice.

This applies to everything: website pages, lead magnets, email
sequences, ad copy, and internal planning docs. If you're adding new
content to this repo, check it against this rule before committing.
